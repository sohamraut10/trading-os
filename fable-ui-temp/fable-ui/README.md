# Fable UI

A cinematic, voice-first personal finance AI interface built with Next.js 15, TypeScript and Framer Motion.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:3000.

Click/tap the **Hold to Talk** control to cycle through Idle → Listening → Thinking → Speaking states.

## Included
- Responsive mobile-first 393×852 experience
- Desktop 1440×900 instrument-panel layout
- Animated CSS orb with halo, dust and orbital rings
- Four assistant-state accent colors
- Portfolio, market pulse, insight and activity surfaces
- Film grain, vignette, glass surfaces and premium dark visual system
